Desktop
≥ 1280px

1024px – 1279px
Content column scales to ~65% viewport. Reduce hero font to ~52px. Maintain side padding ≥ 40px.

768px – 1023px
Single column layout. Tool cards stack 1-per-row. Nav links collapse to vertical list. Hero font ~40px.
Mobile
< 768px
Full-width content, 20px side padding. Hero font ~32px. Project rows stack vertically. Testimonial cards scroll horizontally.
