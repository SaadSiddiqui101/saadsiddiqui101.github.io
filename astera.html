Building Data Integration Platform

Overview

Astera made a fundamental shift in how they delivered value, moving from isolated software installs to a cohesive, integrated platform.


As a solo designer, I worked with the team for the transition of this suite into a modern, web-native cloud ecosystem.

Challenge

  • Transitioning complex Windows-native software to a high-performance web environment.
  • Enabling users to extract data intelligence without launching the full software suite.
  • Replacing manual, email-based licensing with an automated, self-service model.

Solution

  • Designed a centralized hub for user administration, billing, and software launching.
  • Designed high-density tool like data governance platform for AI-assisted data management and interactive Lineage & Impact graphs.
  • Built an internal portal for sales to automate subscriptions and feature toggling.
  • Launched a hub for users to download and integrate pre-built data workflows.
  • Built a responsive, atomic system integrated with Storybook.js for seamless dev-handoff.

Outcome

  • Successfully shipped the core infrastructure for Astera’s web ecosystem.
  • Significantly cut development time through a component-driven workflow.
  • Streamlined operations by replacing manual credential sharing with an automated licensing engine.
